# 8MED — maquette catalogue B2B

Apercu public d'une maquette de boutique B2B pour le materiel medical et
hospitalier. **8MED est un nom provisoire.**

Ce qui est REEL : l'arborescence produits — 14 rayons, 59 familles,
227 sous-familles — et toute la mecanique B2B (facettes recomptees sur le
resultat courant, paliers de quantite, commande rapide par reference, fiche
produit, compte client avec grille negociee, demande en devis plutot qu'en
paiement carte).

Ce qui est de la DEMONSTRATION : les 908 articles, les marques et les prix.
Ils sont generes de facon deterministe a partir du nom de la sous-famille,
dans des fourchettes credibles par rayon. Aucun catalogue fournisseur n'a ete
copie, aucune photo produit n'est utilisee.

Pour essayer le compte client : bouton « Se connecter » en haut a droite, les
identifiants sont pre-remplis. Rien n'est verifie — le bouton bascule
l'affichage des prix, il n'authentifie personne.
